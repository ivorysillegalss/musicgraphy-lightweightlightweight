## 1. 新版产品理念（一句话）

> **Musicgraphy 2.0 是一座以"找得回"为第一美德的个人音乐线索库：记录时以零强制埋下未来的线索——听的时期、一句"当时/为什么"、封面的颜色；找回时凭任何一根残缺线索，经试错式筛选在一屏封面之内重新"认出"；档案偶尔以确定性时间锚自己开口——今天替你保管"为什么留下它"，十年后替你回答"我曾经是谁"。**

一句话版本：**记录即埋线索，找回靠再认，档案偶尔开口——一部可以检索的个人音乐自传。**

理念的合成来源：A2 的"让记录快到敢于记录，让找回只需要一根残缺线索" × A3 的"档案价值 = 记录数量 × 线索密度" × A5 的"用专辑写成的自传" × A4 的"会自己开口说话的档案馆" × A1 的"先保证每一条都找得回来，再谈好看好听"。

## 3. 四大理念支柱

### 支柱一：记录即编码——档案的价值 = 记录数量 × 线索密度
记录不只是"低成本保存"，更是"以零强制为未来的自己埋线索"。三根线索：**听的时期**（listenedAt）、**一句"当时/为什么"**（Note 占位提问）、**封面主色**（派生字段）。编码窗口每天关闭一次——当天没记的"为什么"十年后无法回补；因此线索采集必须嵌在确认瞬间，而不是留给"以后从容补"（以后会补的用户趋近于零）。
〔来源：A3 编码机制；A5 不可逆缺席论证；A2 确认层形态；A1 成本纪律 ≤2 次点击可跳过〕

### 支柱二：找回的完成态是"再认"，不是"想起"
模糊记忆是试错式的：先筛 Electronic，看到太多，才想起封面是蓝色。因此筛选必须匹配试错循环——常驻 chips、每加一个条件立即看到"还剩 N 张"、条件联动收敛、无"应用"按钮；结果一律封面墙呈现。验收：≤3 次筛选 + 10 秒扫视，候选缩到一屏（20–40 张）以内，全程封面可见。找得回的本质，是不依赖用户当年有预见性。
〔来源：A2 形态不可返工论证；A3 再认原则；A1 验收口径；A4 筛选舱规范〕

### 支柱三：集合语义与数据铁律——档案是"为什么留下它"的索引，不是"什么时候放过它"的日志
一专辑一记录；重复添加 ≠ 收听事件（重复 → 温和提示转化为整理；重听 → 显式动作更新 listenedAt）；外部元数据可替换、用户数据是资产、全量可导出；时间轴是最珍贵的记忆数据，不允许被误点与犹豫污染。
〔来源：A1+A2+A3 三方反驳 A4 事件模型、A4 让步；A5 三方仲裁案；A4 本人的档案/日志分界线〕

### 支柱四：档案偶尔开口，永不开口猜你
回顾的唯一触发机制是**确定性时间锚**（"一年前的今天"）：只引用用户自己的过去，零外部语义、零猜测、零推送、零打扰——这与"不是推荐引擎"的围栏不冲突（禁的是猜测未来，不禁自我引用）。档案可以主动，但不可以殷勤。
〔来源：A5 围栏重释（获 A3/A4 采纳、A1 接受其最小形态）；全光谱四方独立收敛；A1 四条形态约束〕

**方法论三尺**（与四支柱同级的制度遗产）：**双用途原则**——凡只能干一份活的新概念，一律沉 P2 或进不做清单（A4 提出，A3/A5 收编为设计定理）；**观察池**——愿景不决定立项，用户行为证据决定（A5 提出，A1 全盘采纳）；**验收口径**——没有口径的功能挖掘只是堆砌（A1 提出，全员采纳）。

## 4. 数据铁律（今天就要写进文档的一行字决定）

1. **listenedAt 语义**：= 最近一次听的时间；默认 = addedAt；用户可改；允许年份级粗粒度输入（"大概 2012"）。它是"听的时期"轴、那年今日、未来收听史三个功能共同的数据底座——语义未定，三者都是沙上建筑。〔A1 升级 P0；A3 判为前置依赖；A4 认可趁早〕
2. **集合语义**：`Album Metadata 1 — N Collection Record` 不变；Collection Record 对 album 唯一；重复添加 = 转化提示 + 可选"又听了一次"（更新 listenedAt），永不产生第二条记录或事件流。〔A1/A2/A3 裁决、A5 仲裁、A4 让步〕
3. **封面主色**：记录/导入时顺手提取，归入 12–16 离散色板，存为 Collection Record 上的派生字段——P0 数据基建；筛选 UI 进 P1。提取可从存量封面批量回填，但记录时顺手算的成本≈0，"编码即资产"。〔A2/A3/A4 多数；A1 的"可回填性"论证被吸收为 UI 不进 P0 的理由〕

## 7. 关键分歧裁决记录（八案）

**案 1 · 收听事件模型 vs 集合语义**（A4 vs A1/A2/A3/A5）
裁决：**集合语义胜**。三方独立反驳（时间轴污染 / 语义漂移 / 新数据对象违规）+ A4 引用的档案/日志分界线反噬自身 + A5 三方仲裁案；A4 二轮正式让步（"低复杂度原则赢了数据浪漫主义"）。A4 对的部分（语义必须趁早定）吸收为第 4 节数据决定。

**案 2 · Review 项进 P0（A5）vs P0 门禁 = Record/Find（A1）**
裁决：**门禁胜，但"那年今日"以 P1 首位放行**——四方独立收敛 + 零新数据 + 通过 A1 修订后的性质判据，为 P1 位置的中位解（A5 P0 / A2·A3·A4 P1 / A1 P2-low）。附四条约束：无推送、单入口、单卡片、确定性时间锚。策展语义不进 P0（第二套状态），但绑定"与 Topster 首版同期生效"的时限承诺（A5 底线采纳）。A5 让步形式、A1 让步存在性——本案是"碰撞后收敛"的范本。

**案 3 · 手动建卡兜底（A4 红线 vs A1 #17 / A2 复杂度）**
裁决：**P2 观察池 + 红线预锁**。A4 的结构修复成立（A1 #17 禁的是"覆盖公共事实"；"外部无数据时的补缺"与 §4 不冲突——用户值标记来源、永不回写），但 A2 的"全员承担永久复杂度"担忧同样成立；冷门藏品是少数场景，MVP 不背。信号 = 搜索失败率。

**案 4 · 命名视图（A2/A3 vs A1）**
裁决：**P1 附条件放行**（仅保存查询状态，非专辑集合；与 Topster 同构，零新概念）。A1 的反对意见与观察信号（反复手工重建同一组合）留档；若信号不出现，自动降观察池。

**案 5 · 封面主色的层级（A2/A3/A4 P0 vs A1 P1）**
裁决：**拆分**——提取存字段 = P0 数据基建（三方多数 + 成本≈0 + "编码即资产"）；筛选 UI = P1（A1 的可回填性论证被吸收：无可逆性损失，故 UI 不占 P0）。双方各赢一半。

**案 6 · 结果打乱（A3 P0 vs A1/A2）**
裁决：**P2 按钮**。再认的关键是候选集足够小；实时计数已服务于此，顺序随机在"一屏以内"时价值趋近于零。

**案 7 · Favorite 熵耗尽解法（A2 拖拽 TopN vs A4/A5 反驳）**
裁决：**A4 处方胜**——重听（行为信号）+ Topster 策展（表达层）承接，数据层零新增字段；拖拽 TopN 降为带重开条件的预案（熵耗尽现象持续则重议）。注：A5 二轮以"排名是随时间变化的历史事实序列，放数据层等于只保留最后一个、销毁历史"**独立得出同一反驳**（A4 从双用途原则、A5 从十年认识论，两条路径同一结论）——本案实为两方独立收敛，置信度上调。

**案 8 · 延申支线准入判据（A1 数量 ≤1 vs A3 性质判据）**
裁决：**A3 性质判据胜，A1 采纳**（砍掉测试 + 零新对象测试 + 不新增页面，逐条过检，不设数量上限）。A1 自己的"三年前的今天"一行字已构成反例——规则必须能解释规则制定者自己的行为。

## 10. 终稿结语

这次评审最有价值的产出不是任何一个功能，而是三处"碰撞后收敛"：激进者（A4）在数据浪漫主义与低复杂度原则之间选择了后者；守成者（A1）用自己的不可逆尺子量出了自己的漏洞并修补了方法论；未来主义者（A5）用守成者的尺子为自己的"为什么"提问赢得了 P0 的一席——**每个人的最终方案都比他第一轮的方案更好，而且没有一个人全赢**。

产品的第一美德不是功能多，而是十年后翻回去时：**每一条都还在、都认得出、都带得走、都还记得自己为什么被留下。**
