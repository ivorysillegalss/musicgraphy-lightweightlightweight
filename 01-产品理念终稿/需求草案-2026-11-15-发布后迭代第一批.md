## R-101 Topster 内容描述页面（→ 看板卡 S2-1）

- **需求原文**：「在看板的第二阶段增加个topster的内容描述页面」。
- **背景**（2026-11-15 全站入口普查实测）：`/topsters` 系列（列表/策展页/海报页/SVG 导出）**无任何 UI 入口**
  （四页 HTML 共 0 处 topster 链接），也无功能说明——只能手敲 URL。
- **草案方向**（实施时定稿）：
  ① 独立说明页：Topster 是什么 / 怎么建 / 分享价值（衔接 04B 引擎一「分享的是作品图不是产品」+ 海报页 + SVG 导出链路）；
  ② `/topsters` 空态引导增强 + 全站页脚入口链接（顺带闭环入口缺口，与 W10-12-1 交付的导出入口呼应）。
- **开放问题**：页面形态、入口位置、是否与导出动作串联引导。

## R-102 登录用户信息呈现

- **需求原文**：「当前页面中没有登陆 用户的相关信息」。
- **现状**：单用户密钥制（V10 cookie 会话 HttpOnly HMAC），全站无登录态标识——页面不显示任何「谁在用」的信息。
- **草案方向**：页头或页脚登录态区（如「已解锁 · Musicgraphy」+ 会话剩余期 + 退出动作）。
- **开放问题**：单用户制下呈现什么；是否顺势引入多用户概念（数据模型 user_id 字段已预留，但产品定位 = 个人档案，
  多用户涉数据模型与隐私面，属架构级决策）。

## R-103 动效框架接入 React（用户已确认裁决）

- **需求原文**：「当前为了实现动效 我确认需要接入react框架作为实现 后期可以将性能优化作为专项」。
- **裁决状态**：**用户 2026-11-15 明确确认**（裁决序最高，本文档 = 裁决事实源）。实现载体与「专项二 S-B：前端页面的
  动效显示」合并执行路径（S-B = 动效范围与形态的主人，React 为其实现框架）。
- **⚠️ 红线影响披露（实施前必须逐项处理，当前未动任何代码）**：
  1. **G1 护栏「运行时依赖 ≤2」将被突破** → 实施时须修订 G1 口径（新预算数值评审定）；
  2. **「无 JS 基线」架构红线**（ADR-003 SSR 岛屿 / IM-19「htmx 不引入」同族）→ React 接入形态须评审案：
     局部岛 hydration（保 SSR 直出）vs 整页接管（改架构），二者成本与风险差异巨大；
  3. **性能优化后置专项**（用户钦定）→ G2 RSS 预算与首屏体积预算在专项内重核（现基线：首屏 JS 2.33KB、
    岛屿 chunk ~11KB 懒加载、main.css 19.02KB——React 运行时体积远超此量级，预算全面重算）。
- **实施前置清单**：动效范围清单（哪些页面哪些交互要动效）→ 接线形态评审案 → G1/G2 口径修订（用户追认）→
  分阶段迁移 → IM 登记。

## R-104 封面墙下拉限制

- **需求原文**：「当前的下拉是无止境的瀑布流 我需要限制」。
- **现状**：FR-5 wall-scroll 岛屿无限追加（IO 预取 + cursor 服务端顺链，has_next=false 才停）——数据多时可一直滚。
- **草案方向**（候选，实施时定）：
  a) 追加 N 页后改「加载更多」手动按钮；
  b) 到底提示 + 返回顶部；
  c) 硬上限 + 「已到底 · 共 N 张」计数提示。
- **开放问题**：N 值、形态选择、与 5000 张压测基线（IM-20：可交互 34.4ms）的回归关系。

## R-105 Genre / 年份筛选呈现改版

- **需求原文**：「当前的geners和年份筛选 当前我需要用别的方式呈现」。
- **现状**：筛选舱 chips（genre 一排 22 项 + 年份一排 75 项 + 听期/收藏/Tag/颜色轴），chips = `<a>` URL 即状态（DD3）。
- **草案方向**（候选）：genre 分组下拉或侧栏；年份区间选择（双下拉/滑块）。
- **开放问题**：形态、chips 去留、与 R-103 动效的联动、**URL 即状态红线必须保持**（筛选状态仍须可分享可后退）。

## 专项一 S-A：搜索功能的优化（→ 看板卡 S2-2）

- **需求原文**：「创建两个新的专项：搜索功能的优化和签单页面的显示」（签单页面经用户澄清 = 前端页面的动效显示 → 专项二）。
- **现状锚点**：本地四字段 LIKE 1–2ms 性能无忧（W4-6-2 perf-like，5000 行实测）；search-box 双意图候选（你的档案 + 外部）；
  R1 快照回放缓存（B4，TTL 10min/FIFO 256）；全局限流 30/min + Bearer 备用。
- **专项范围开放**（实施前评审定稿），候选方向：
  本地检索相关性（LIKE → 分词/加权/拼音?）、候选排序与呈现、防抖与交互体验、零结果空态、跨源候选聚合体验。
- **跨线属性**：后端检索质量 + 前端呈现双面；看板载体卡挂 FRONTEND 线（S2-2），实施时按范围拆分落线。

- **需求原文**：「创建两个新的专项：…签单页面的显示」，经用户澄清 = **前端页面的动效显示**。
- **与 R-103 的关系**：R-103 = 框架裁决（React，已确认）；S-B = 动效的范围与形态主人（哪些页面、哪些交互、什么风格），
