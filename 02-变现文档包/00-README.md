## 一、两套方案与权重模型

用户决策（2026-11-06）：**当前阶段产品主线不考虑盈利点 / 降低盈利权重**。据此给出两套完整方案：

| 目标维度 | 方案 A（盈利优先） | 方案 B（增长验证优先）✅ **当前默认执行** |
|---|---|---|
| 核心闭环质量 Q | 0.35 | **0.40** |
| 留存 / 验证信号 V | 0.20 | **0.30** |
| 增长 / 传播 G | 0.15 | **0.25** |
| 变现 M | **0.30** | 0.05 |
| 复杂度控制 C | **硬约束**（一票否决，不进权重） | 同左 |

- **方案 B = 现在执行**：免费全量、成本压到≈0、增长靠自传播与理念内容；支付/定价**只预留接口不实现**（feature flag `billing_enabled=false`）。
- **方案 A = 切换预案**：B 的触发条件达成后（见 04B §5），2 周内无缝切入（Pro 权益、定价、支付集成均已在此包中定义完毕）。
- 两套方案**共用**同一 PRD、数据模型与发布文案主体；差异只在路线图、商业化与落地页定价区，均已双版本化。

## 三、贯穿全套的三条不变红线（来自终稿支柱三与不做清单）

1. **核心闭环永久免费**：记录 / 整理 / 找回 / 基础回顾，任何方案下不收费。
2. **数据主权永久免费**：全量导出永远免费——"拿得走"是"敢积累"的前提，也是信任资产。
3. **不打扰变现**：无广告、无推荐位、无以变现为目的的通知/推送（档案只以确定性时间锚开口）。

任何一方（包括未来的自己）想突破这三条，先重读终稿第 7 节裁决记录。

## 四、观察池仪表（两套方案共用的验证仪表盘）

| 指标 | 定义 | 服务于 | 方案 B 中的角色 |
|---|---|---|---|
| 线索覆盖率 | 携带 ≥1 根个人线索（Note/Tag/听期）的记录占比 | 北极星 | 核心健康度，发布起观测 |
| 搜索失败率 | 搜索无结果会话占比 | 观察池升级信号（手动建卡） | 体验红线 |
| 命名视图创建密度 | 每周人均新建命名视图数 | Era 信号 / 命名视图价值验证 | P1 验证 |
| 回响卡片点击率 | "一年前的今天"点击占比 | Review 触发器有效性 | 留存验证 |
| "为什么"回访率 | 详情页 Note 区回访占比 | 编码价值验证 | 留存验证 |
| 导出使用率 | 导出动作会话占比 | 数据主权感知 / A 方案付费意向代理 | 切换 A 的前置信号 |
