## 各阶段要点

**W1–W3 骨架**：02 文档建表 → FR-1 三捷径与确认层（含 Tag 补全、Note 折叠、快捷听期）→ FR-4 三条数据决定随建表落死 → 中密度网格 + 虚拟滚动。⚠️ W3 末做 FR-6 性能预算首轮压测（预算=验收标准，不过不进入下一阶段）。

**W4–W6 找回**：FR-2 chips + 实时计数（两 SQL 往返）→ FR-3 四字段检索 → D3 主色提取管线 + 回填脚本 → 色板 UI（P1-4）。W6 末：找回忆于口述验收——"蓝色封面的那张电子"场景实测 ≤3 筛 + 一屏。

**W7–W8 体验与 Pro 打包**：P1-1 回响卡片 / P1-2 记忆条 / P1-3 导出 / P1-6 Tag 治理 / P1-7 重听动作；Pro 权益实现（04A §3）：Topster v1 + 策展模型（同期生效）+ 高清导出 + 主题系统 + license 校验桩。观察池埋点全开（PRD §6）。

**W9–W10 变现与发布**：Lemon Squeezy/Paddle 集成（license 签发与校验）→ 定价页（05 文案 A 变体）→ 落地页上线（06-landing.html 切方案 A）→ Product Hunt / V2EX / 即刻发布 → 转化漏斗看板（访问→注册→首次记录→7日留存→付费）。

## 风险与对冲

- 支付与税务合规占 W9 约 3 天缓冲；若延误，先发布免费版，支付延一周（**发布不等待变现**）。
- Pro 权益若挤占核心打磨时间：砍主题系统的丰富度（1 套 Pro 主题即可），**不动 P0**。
- 两方案通用红线（00-README §三）全程有效：核心闭环与导出永久免费。
