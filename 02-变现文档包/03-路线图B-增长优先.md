## 各阶段要点

**W1–W6 与方案 A 完全一致**（Q 权重最高，核心闭环不为任何目标让路）。差异从 W7 开始。

**W7–W9 留存与信任**（V 0.30 的兑现）：
- P1-1 "一年前的今天"回响卡片（留存触点，四条约束）；
- P1-2 详情页记忆条（"想起它对我是谁"——情感落点）；
- **P1-3 档案导出提前至本期**：数据主权是最强信任资产，"拿得走→敢积累→肯口碑"（信任链）；
- P1-6 Tag 治理、P1-10 命名视图（用户检索语言的沉淀 = 留存的 sediment）；
- 观察池仪表全开：线索覆盖率 / 搜索失败率 / 命名视图密度 / 回响点击率 / "为什么"回访率（PRD §6）。

**W10–W12 自传播包**（G 0.25 的兑现）：
- Topster v1 + 最小策展数据模型**同期生效**（副标题 + 顺序可保存；禁自由画布）；
- Topster 导出图片（社交媒体分享的是作品图，不是产品——零成本自传播面；PRD §5 方案 B 调整 1）；
- 落地页上线（06-landing.html，默认方案 B 模式："免费 · 无广告 · 数据可带走"）+ 05 文案全渠道发布（PH / V2EX / 即刻 / RYM·Discogs 社区）；
- **成本≈0 架构核对**（04B §3）：静态托管 + 免费 metadata 源 + 本地缓存，确认月成本 < $5。

**W12 末 · 决策门**（04B §5 触发条件评审）：
| 指标 | 达标线 | 未达标动作 |
|---|---|---|
| 活跃档案数（≥30 条记录的用户） | ≥ 100 | 延长 B 一个周期，聚焦 onboarding |
| 线索覆盖率 | ≥ 40% | 优化确认层埋点文案，不加功能 |
| 回响点击率 | ≥ 15% | 检查卡片打扰度，考虑形态回撤 |
| 导出使用率 / 自然传播提及 | 有记录的口碑出现 | 强化自传播包 |
- **任一组合达标 → 启动方案 A 切换**（04A，2 周支付集成）；全线未达标 → 继续 B 并诊断（变现继续延后）。
