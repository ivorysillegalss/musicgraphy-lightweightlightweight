# 04A · 商业化与变现方案（盈利优先 · 方案 A）

> 前提：本方案在"方案 B 触发条件达成后"启动（04B §5），或用户主动选择盈利优先。
> 三条不变红线（00-README §三）：核心闭环永久免费 / 导出永久免费 / 无打扰变现。

---

## 1. 定位与人群

**定位**：个人音乐档案工具——"你的音乐自传，从三秒记录开始"。
**付费人群画像**（从免费用户中自然长出，不强推）：
1. **重度档案党**（RYM/Discogs 用户）：500+ 张记录，愿意为"更好看的表达"（Topster 高清导出）付费；
2. **多设备记录者**：手机听到、桌面整理，需要云同步/备份；
3. **审美敏感型**：愿意为主题外观付费（玩具属性变现，A4"东西本身好玩"）。

**竞品参照**（模式验证证据）：
| 产品 | 模式 | 对 Musicgraphy 的启示 |
|---|---|---|
| Letterboxd（电影） | 免费 + Pro $19/年 + Patron $49/年 | 个人档案 + 订阅模式在同类利基被验证 |
| Discogs | 免费 + Marketplace 抽成 | 不适合（我们不做交易） |
| RYM | 免费 + 付费解锁高级筛选 | 高级检索可以是付费点，但**我们已把核心找回定为永久免费**（理念红线），付费点必须选在"表达与便利"层 |
| Notion | 免费 + 团队订阅 | 个人工具靠团队/协作变现 → 我们不做多用户，不适用 |

## 2. 变现模式对比与推荐

| 模式 | 优点 | 缺点 | 与理念相容性 | 结论 |
|---|---|---|---|---|
| 广告/推荐位 | 无需用户付费 | 破坏"不打扰"与专注 | ✗ 违红线（不做清单） | 排除 |
| 纯订阅 | 收入可预期 | 个人工具订阅疲劳；与"档案是资产"心智冲突 | △ | 不推荐 |
| **一次性买断 Pro** | 一次付费终身可用，契合"长期档案"心智；无续费焦虑 | 收入不可预期 | ✓ 完全相容 | **推荐主模式** |
| 年费可选 | 给想持续支持者出口 | — | ✓ | 推荐辅模式 |
| 捐赠/赞助 | 零摩擦 | 收入微小 | ✓ | 常设一行字入口（04B 已布） |

**推荐定价**（锚点：Letterboxd Pro $19/年；独立工具买断常见 $19–39）：
- **Musicgraphy Pro · 买断 $29**（首发 $19）
- **或 Pro · 年费 $12**（给低门槛出口；两者并存由用户自选）
- 免费用户永获：完整闭环、全量导出、Topster 基础版（低清导出）。

## 3. Pro 权益表（严格不碰核心闭环）

| 权益 | 免费 | Pro | 理念校验（双用途/红线） |
|---|---|---|---|
| 记录/整理/找回/基础回顾 | ✓ | ✓ | 核心闭环永久免费 |
| 全量导出 JSON/CSV | ✓ | ✓ | 红线：永久免费 |
| Topster 创建与低清导出 | ✓ | ✓ | — |
| **Topster 高清导出（2K/4K·无水印）** | ✗ | ✓ | 表达层变现（A2 P2-4 兑现面） |
| **自定义主题 / 封面墙外观** | 1 套默认 | 全部主题 | 玩具属性变现，零功能锁 |
| **云端备份与多设备同步** | 本地 | ✓ | 便利层；本地文件始终可导出——不锁定 |

**不做成付费点的东西**（防暗模式清单）：找回相关的一切（筛选轴/检索/计数）、Tag 数量上限、Note 长度、导出、历史数据访问。

## 5. 转化漏斗与时机

`访问落地页 → 注册 → 首次记录（Aha：3 秒留住一张专辑）→ 7 日留存（回响卡片/记忆条触发回顾）→ 第 N 次导出或 Topster 制作（价值峰值）→ Pro 弹出（仅在此刻，一次性）`
**触发时机**：用户**第二次**制作 Topster 或**首次**尝试多设备时弹出一次性 Pro 提示；永不弹窗打扰（红线）。
**从 B 切入的前置信号**：导出使用率（付费意向代理）连续 4 周 ≥ 10%。
