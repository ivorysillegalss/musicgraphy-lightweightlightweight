# 04B · 零盈利增长方案（当前阶段 · 方案 B）

> 用户决策：当前产品主线不考虑盈利点（盈利权重 0.05）。本方案回答："不赚钱的阶段，胜利长什么样？"
> 三条红线继续有效：核心闭环永久免费 / 导出永久免费 / 无打扰。

---

## 1. 本阶段的胜利条件（替代收入的目标函数）

| 目标 | 定义 | 为什么它比收入重要 |
|---|---|---|
| **档案活跃度** | ≥30 条记录的活跃档案数 | 收入的前提是"档案值得付费"，先让档案值得积累 |
| **线索覆盖率 ≥40%** | 北极星 | 空档案是产品失败的最高形式（A5：空档案比慢一秒的记录更致命） |
| **自然口碑** | 无投放情况下的自发提及/转发数 | 利基产品的唯一真实增长引擎 |
| **留存** | 7 日回访（回响卡片是钩子）、30 日仍在记录 | 档案产品的时间复利 |
| **理念被引用** | 用户/社区复述"记录即埋线索""档案偶尔开口" | 理念即品牌，被复述=心智占领 |

## 2. 免费全量策略（明确"不收费"清单）

- 全部 P0 + P1（含导出、命名视图、Topster 基础版）免费；
- **不设**：功能墙、次数墙、存储墙、时间墙；
- 唯一"预留"：feature flag `billing_enabled=false` + entitlements 表位置已声明（02 §6）——**预留接口 ≠ 预留暗门**，flag 关闭时用户不可感知其存在。

## 3. 成本压到 ≈$0 的架构决策（增长期纪律）

| 决策 | 内容 | 依据 |
|---|---|---|
| 静态优先部署 | 前端静态托管（Cloudflare Pages/Vercel 免费层）+ 边缘函数 + SQLite/KV | 月成本 < $5 容忍线 |
| 元数据零成本 | MusicBrainz（免费主源）+ Deezer/iTunes Search 免费接口 + 本地快照缓存 | 02 §5.1 降级链 |
| 图片不自建库 | 封面源站直链 + 本地缓存（已缓存即永久可用） | — |
| 无付费基础设施 | 不接支付、不建账单系统、不买邮件营销工具 | flag 预留即可 |
| 统计极简 | 自托管匿名计数（可关闭），不用付费分析栈 | 隐私=信任资产 |

**月度成本硬顶**：$5。超出即触发架构复盘（通常意味着某个免费源变了——查 02 §5.1 降级链）。

## 4. 增长机制（不花钱的三台引擎）

### 引擎一：作品图自传播（主引擎）
Topster 高清导出图片 → 用户自发贴到社交媒体；**图片角落一行小字**："made with Musicgraphy"。分享的是用户的表达（不是我们的广告），产品只是署名——完全符合"不做社交功能"红线（分享发生在平台外、用户之手）。〔A2 P2-4 洞察，B 方案提前启用〕

### 引擎二：理念内容营销
把评审终稿变成公开内容（它本身就是最好的品牌资产）：
- 博客/长文：《我们用 5 个 AI 评审者做了一次产品推演》（过程即故事，附收敛图谱）；
- 理念短文系列："记录即埋线索""找回的完成态是再认""档案偶尔开口"——每篇一个支柱，可被转发的观点件；
- 对比内容："为什么 Musicgraphy 拒绝做推荐引擎"（不做清单作为差异化宣言）。

### 引擎三：社区渗透（利基精确打击）
| 社区 | 角度 |
|---|---|
| RYM / Discogs 社区 | "你的 RYM 收藏值得一个更私人的家"（补位，不对抗） |
| Letterboxd 用户 | "电影有 Letterboxd，音乐值得一个同样的地方"（品类嫁接） |
| V2EX / 即刻 / 小红书 | 独立开发叙事 + 手帐/记录人群 |
| GitHub（可选开源） | 核心开源 + 云端服务闭源——信任与贡献者双重收益（**可选**，与"个人玩具"定位不冲突；开源不改变任何产品决策） |

### 常设插座：一行字赞助（不是变现，是姿态）
页脚固定一行："Musicgraphy 永远免费。如果它帮到了你，[请我喝杯咖啡]。"——GitHub Sponsors / 爱发电。零打扰、无弹窗、无进度条、无目标金额公示（那是众筹话术，不是赞助姿态）。

## 5. 切换到方案 A 的触发条件（数值化，全部满足才切换）

| # | 条件 | 阈值 | 依据 |
|---|---|---|---|
| T1 | 活跃档案数 | ≥ 100 个（≥30 条记录） | 有付费人群的最低基数 |
| T2 | 线索覆盖率 | 连续 4 周 ≥ 40% | 档案有价值 = 有人愿意为表达层付费 |
| T3 | 自然口碑 | 累计 ≥ 20 次无利益自发提及/转发 | 增长引擎已被验证 |
| T4 | 导出使用率 | 连续 4 周 ≥ 10% | 数据主权感知强 → 信任付费（04A §5 前置信号） |
| T5 | 成本 | 月成本连续逼近 $5 上限 | 免费模式难以为继的工程信号 |
- **全部满足** → 启动 04A §6 切换清单（2 周）；**部分满足** → 针对性优化对应引擎，不切；**T5 单独满足** → 只做成本优化，不切（成本问题用架构解决，不转嫁用户）。
- 触发条件评审每 4 周一次，记录在决策门（03-路线图B W12 末及每 4 周滚动）。

## 6. 本阶段明确不做（负清单）

支付 / 定价页 / 促销码 / 邮件营销 / 增长黑客式弹窗 / "邀请好友得 Pro"（没有 Pro） / 任何 A/B 测试打扰用户的实验。
