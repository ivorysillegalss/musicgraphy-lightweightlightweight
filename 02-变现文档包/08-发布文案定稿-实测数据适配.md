## 3. 渠道发布模板定稿（适配实测数据 + Topster 卖点）

### 3.1 Product Hunt 首评（Maker comment）

> I've been logging music for years, and the real pain was never "finding new music" — it was finding back the albums I already own. After 500 records, a collection list stops working: you only remember a fuzzy clue — a blue cover, the year you listened, one sentence you wrote.
> Musicgraphy is built for exactly that: 3-second recording, trial-and-error filtering that tells you "N left" with every click (5000-album wall renders interactive in 34ms — measured, not claimed), color-of-cover search, and "On This Day" echo cards that only ever quote your own past. No recommendations, no social feed — it's your archive, not your timeline. Core features free forever, full data export anytime.

### 3.2 V2EX / 即刻（独立开发叙事）

> 分享一个我给自己做的音乐档案工具：不推荐、不社交、不做播放，只解决「记得到 + 找得回」两件事。
> 技术上克制得有点固执：运行时依赖只有 2 个包（Hono + node:sqlite），没有搜索引擎、没有 AI、没有消息队列——5000 张专辑首屏可交互实测 34.4ms，四字段模糊检索 1–2ms。产品上同样克制：P0 只有两屏，找回收敛要求 ≤3 次筛选一屏认出（实测 325→86→27 张）。
> 附：我们用 5 个 AI 评审者做产品推演的完整过程（见 09 素材稿其一）。核心功能永久免费，数据一键导出带走。欢迎拍砖。[链接]

### 3.3 小红书 / 手帐人群

> 把「我听过什么」变成一本可以翻的音乐手帐📖
> 三秒记下一张专辑，留一句当时的心情；「一年前的今天」它会自己开口提醒你——只引用你自己写下的过去。
> 年度 Top 25 图：从你的收藏里挑一组、排好顺序、写一句副标题，一键导出带署名的分享图（SVG 高清 + 网页海报截图皆可）。
> 免费、无广告、无追踪，数据随时导出带走。

### 3.4 RYM / Discogs 社区（克制版）

> Built a personal album-archive tool (not a database project, not for trading): cover-first collection grid, fuzzy-memory retrieval (cover color / listening period / your own notes — 1–2ms LIKE search over 5000 rows), and a Topster-style curation view (order + subtitle, exported as SVG with "made with Musicgraphy" signature). Local-first SQLite, two runtime dependencies, no recommendation engine. Meant to complement database projects, not replace them. Feedback welcome.

### 3.5 即刻 / 推特短版（自传播配套，供转发引用）

> 「收藏列表滚不到底」的解法：把每张专辑存成一条可检索的线索——颜色、听的年份、你写过的一句话。三次筛选以内，一屏认出。免费，无追踪，数据可带走。

## 4. FAQ 定稿（与 05 §2 FAQ 一致 + 两条实测补强）

- Q: 和 Discogs/RYM 有什么区别？ A: 它们是公共数据库，Musicgraphy 是你的私人档案——Genre 是音乐的属性，「夜晚」才是你的属性。
- Q: 会一直免费吗？ A: 记录、整理、找回、导出——核心功能永久免费（即便未来出现付费项，也不会碰这些）。
- Q: 需要填很多信息吗？ A: 不。搜索→确认→添加，三秒完成；其他一切都是可选的。
- Q（补强）：数据真的能完整带走吗？ A: JSON / CSV / 含封面 zip 三通道全量导出，且导出文件经「可重建档案」验证——重建后档案完整度指标与原库一致（不是承诺，是测试断言）。
- Q（补强）：它智能吗？ A: 它不猜你。没有推荐引擎、没有画像、没有推送；「一年前的今天」只引用你写下的过去。检索是确定性的：你给线索，它给结果。
