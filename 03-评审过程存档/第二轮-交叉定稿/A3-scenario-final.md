# A3 记忆研究员 · 第二轮最终主张

人设维持：发散度 3/5，稳定度 3/5。本轮立场：核心结论不变（编码—再认—触发的记忆链路），交互形态与数据语义按交叉交流的结果修正。

---

## 1. 吸收（来自谁的什么主张，如何融入）

### 吸收 1（来自 A2）：筛选 chips + 实时命中计数 + "先添加稍后补"

- **融入方式**：我第一轮的"一屏原则"只有理念（"还剩 N 张"），没有交互形态。A2 的 P0-3（常驻 chips + 实时计数 + 条件联动收敛 + 无应用按钮）就是它的正确形态。记忆科学负责"为什么"——模糊记忆是试错式的，"先筛 Electronic，看到太多，才想起封面是蓝色"，表单式筛选强迫用户一次想全条件，与试错过程冲突；A2 负责"怎么做"。他的 R3 论证（筛选形态选错一次，后面加多少维度都救不回来）说服了我把这条从 P1 升到 P0。
- **第二处融入**：我的 P0-4"当时"微上下文并入 A2 的 Add 弹层三件套——Favorite 开关 + 最近 Tag chips + Note 折叠框（提示语吸收 A5 的"为什么留下它？"）+ 我的"大概什么时候听的"快捷年份选项。同一弹层、全部可选、默认一键完成。A2 的"先添加稍后补"与我的编码观完全兼容：编码可以异步补，但不能没有入口。

### 吸收 2（来自 A4）：联想式找回 + 双用途原则

- **融入方式**：新增 P1"联想入口"——详情页记忆条下方给出"同期听的 / 同天添加的 / 同 Tag 的其他专辑"。零新数据（addedAt/tag 已有），记忆科学上这是激活扩散（spreading activation）的直接实现："和 X 差不多同期听的那张"是真实的找回线索类型，我第一轮漏掉了它——这是交叉交流的真实收益。
- **双用途原则收编为第五条设计原则**：每份新数据干两份活（主色 = 筛选线索 + 色环素材；listenedAt = 时期筛选 + 那年今日 + 收听史；Note = 找回线索 + 手记素材）。这与我的支线观（接线而非扩建）同源，是"低复杂度与高表达力同时成立"的合法通道。

### 收敛确认（不是吸收，是交叉验证）

- **Note 三方收敛**：我（Note 可搜索）、A4（Note 全文检索）、A5（"为什么留下它"引导）三个不同人格从不同路径到达同一结论——这是第一轮最可靠的一条 P0，从"我的主张"升格为"共识主张"。
- **"一年前的今天"四方出现**：我（P1-5）、A5（P0-2）、A2（P2-2）、A1（P2-3 最低位）——存在性无人反对，分歧只在优先级。四方独立出现本身说明"Review 缺触发"是真实缺口。

## 2. 反驳（反对谁的什么主张，理由）

### 反驳 1（A4 · P0-5 重复记录 = "又听了一次"）：两种记忆行为不能共用一个手势

这把两个不同的记忆事实压进了同一个手势——"我把它留下来"（收藏，录入行为）与"我今天又听了它"（重听，重访行为）。若对已存在专辑的"添加"默认生成收听事件：

1. **时间轴污染**：误点、犹豫产生的重复点击都会写进收听历史，而时间轴是"听的时期"筛选、那年今日、未来收听史三类记忆功能共同的数据底座——档案里最不该有噪声的就是它。
2. **语义漂移**："记录"从"我选择留下"变成"我触碰过"，档案混入非意图内容。这与 A1 反对 Last.fm 自动同步的理由完全同构（非意图内容稀释档案价值），A4 自己也签了那条名。
3. **新概念违规**：它在 P0 就引入"收听史"这一新数据对象，违反五方共识的"P0 零新概念/零新对象"。

**替代方案**：重复添加 → 温和提示"已在你 Collection 中"+ 两个出口（去详情页补充线索 / 显式标记重听）——即 A2 P1-4 的形态，把挫败转化为整理机会；"重听"是我 P1-2 的显式独立动作。语义解耦后，两个手势各自干净。

### 反驳 2（A5 · P0-3 Topster 最小策展语义进 P0）：内核认同，时机反对

策展语义（副标题一句话 + 顺序即叙事）挂在 View 层、不产生第二套专辑数据——这个内核我完全认同，它与我的"手记"支线同源：私有叙事是十年后最珍贵的数据。但放进 P0 时机错了：

1. Topster 本身按五方共识是核心后能力（AGENTS.md §9/§13），为一个尚不存在的 View 先建"顺序 + 副标题"的保存状态，等于在核心闭环未验证前产生第二套状态——恰好踩中 A1 整个方案防守的那条线。
2. "十年后无法复原"的论证恰恰说明它不急——它需要的是"尽早开始积累"，即 Topster 首版落地时同步实现即可，晚一个版本不构成损失。
3. AGENTS.md §16 的 P0 每一席都该给 Find/Record，策展挤进 P0 会稀释这个信号。

**折申**：A5 若想更早留下"叙事"痕迹，有一个零状态替代——"手记"视图（我的 P1-3）天然按时间保存用户自己的字，不需要任何编辑器。

### 附加反驳（轻，A1）：唯一延申支线"数量 ≤ 1"的判据过严

A1 用数量上限执行稳定 5/5 的克制，但判据应该是**性质判据**而非**数量判据**：零新数据 + 零新概念 + 不新增页面的支线（我的四条支线全部如此），复杂度成本为零——砍掉它们省不出任何复杂度，只省掉了价值。且 A1 自己的 P2-3（"三年前的今天"一行字）本质上就是我的支线四，规则已被自己的方案违背，说明"数量 ≤ 1"不是好的操作化。我建议 A1 的审查标准改为：支线必须逐条通过"砍掉测试 + 零新对象测试"，不设数量上限。

## 3. 修订后的立场（坚持 / 让步 / 吸收）

### 坚持

1. **再认优先与一屏原则**：P0 检索结果一律封面墙呈现，不动摇；吸收 A1 方法论后补上可检验口径。
2. **Note 必须可搜索、必须进 P0**：三方收敛后升级为共识主张。
3. **"听的时期"轴进 P0**：但新增一个前置依赖（见"吸收·隐性"）。
4. **Review 的底线**：不做 feed、不做推荐、不做排程推送；重遇只用确定性时间锚。与 A5 的"时间容器"对表后这条更清晰：可以吸收"档案自己开口"，不接受"猜你想看"——A5 的"只引用用户自己的过去、禁外部语义猜测"的重划界我认可，这正是我接受"那年今日"而不接受"猜你想重温"的理由。

### 让步

1. "结果内打乱"从独立 P0 条目降为 chips 交互内的一个按钮——形态合并后不再是独立功能。
2. P1-4"还剩 N 张"整条并入 A2 的 chips + 实时计数——同一件事不设两个条目。
3. 接受"封面主色提取"提前至 P0 数据基建层（A2/A4 的"记录时顺手抽主色"），筛选 UI 仍留 P1——数据先行、UI 稍后，这正是"编码即资产"。
4. 接受 A1 的验收口径方法论，我的原则从定性变定量：一次模糊找回 ≤ 3 次筛选、候选缩至一屏内（约 20–40 张）、全程封面可见；"当时"微上下文 ≤ 2 次点击、可跳过、可在设置中关闭（与 A5 一致）。

### 吸收（隐性依赖修正）

1. **A1 的 listenedAt 语义裁决（默认 = addedAt、允许轻量补录）必须前置到我的"听的时期"轴之前**——语义未定则时期轴是沙上建筑。这条从 A1 的 P1 升为 P0 级数据决策，是本轮交叉最有价值的一次依赖发现。
2. **裁决 A1 × A2 分歧（智能播放列表禁令 vs 保存筛选视图）**：支持 A2 的"命名视图"进 P1，条件写死——只保存查询（筛选状态），不保存专辑集合，与 Topster 同构。A1 的禁令针对"系统按规则生成集合"（引入规则概念），A2 保存的是"用户固化自己的一次找回配方"（零新概念），二者不是同类。它对记忆的意义：找回成功的那次线索配方本身值得记住——"我是怎么找到它的"是元记忆。

## 4. 最终产品主张（定稿）

Musicgraphy 2.0 的本质是一座个人音乐记忆的线索库。记忆的完整链路是编码—存储—提取：现有目标重"存储与查询"、轻"编码与再认"，2.0 要补齐两端。记录时，以零强制方式为每张专辑埋三根线索——听的时期（listenedAt，语义须先裁决）、一句可选的"当时/为什么留下它"、封面主色；全部 ≤ 2 次点击、可跳过可关闭。找回时，从任何一根残缺线索出发，经试错式 chips 筛选（实时计数、条件联动）把候选缩到一屏封面以内——找回的完成态是"认出"而非"想起"；验收口径：≤ 3 次筛选、一屏内锁定目标、全程封面可见。私人线索通道必须有三条：Tag、Note 片段、听的时期——Tag 不能是唯一通道。回顾不做推荐、不做 feed，只用确定性时间锚（"一年前的今天"）让档案引用用户自己的过去、零打扰地重新开口。三条关键裁决：一，Note 必须可搜索，这是三方独立收敛的结论；二，重复添加 ≠ 收听事件，重听必须是显式动作，保护时间轴这一最珍贵的记忆数据；三，策展语义挂在 View 层但不进 P0，先让核心闭环站住。十年尺度上，档案的价值 = 记录数量 × 线索密度，而非专辑数量。

## 5. 优先级变化

### 升级

1. **筛选 chips + 实时计数**（原我 P1-4）→ P0：A2 的"形态不可返工"论证成立，这是 Find 的地基形态。
2. **封面主色"提取存字段"**（吸收 A2/A4）→ P0 数据基建，一次性成本；"颜色筛选 UI"维持 P1。
3. **listenedAt 语义裁决**（吸收 A1，原 A1 定位 P1）→ P0 前置数据决策：时期轴、收听史、那年今日三个功能的数据底座。
4. **联想式找回**（新增，吸收 A4）→ P1 高位：零新数据、记忆科学上最强的提取路径之一。

### 维持（含对其他人方案的裁决）

1. 我的五条 P0 全部维持（听的时期轴、Note/Tag 片段搜索、封面墙呈现、"当时"微上下文、详情页记忆条）——其中两条被并入 A2 的形态，但承重墙地位不变。
2. **"一年前的今天"维持 P1**：A5 提 P0 过早（挤占 Find/Record 资源），A2 提 P2、A1 砍至最低位则 Review 永远不会发生——P1 是四方位置的中位解，也是"Review 唯一触发机制"的底线位置。
3. **"手记"视图维持 P1**：不因 A4/A5 的 Note 共鸣而升级进 P0——A1"View 独立裁决、绝不打包"的提醒有效，Review 层不得抢跑。
4. 年度回顾、记忆巡游、色环视图维持 P2。

### 降级

1. 无整条降级；仅有条目合并（"结果内打乱"并入 chips、"还剩 N 张"并入实时计数）。

### 本轮新增不做

1. 不做"重复添加 = 收听事件"的隐式语义（反驳 1）；重听必须是显式独立动作。
2. 不做 Topster 策展语义进 P0（反驳 2）；与 Topster 首版同期落地。
3. A5 的"联想边"（显式数据对象）不进 P1：与 A5 自己的观察池纪律一致——先等 Note 中"让我想起 XX"的自然出现密度，再决定是否官方化。A4 的"派生联想"（零新数据）与 A5 的"联想边"（新数据对象）不是同一条主张，我吸收前者、观望后者。
