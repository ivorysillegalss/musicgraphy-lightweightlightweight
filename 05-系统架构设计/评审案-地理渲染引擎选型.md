## 1. 结论与推荐（待用户追认）

**推荐 MapLibre GL JS（v5.0 起 globe projection 正式内置；npm 当前稳定 = v6.18.0，
v5 线最新 = 5.24.1）作为 /atlas 地图模块的「投影 + 渲染 + 拾取」引擎——零 token、
零运行时外部请求，style / 数据 / 字体全自托管，与乙-5 完全兼容。**

- 裁决范围**仅限渲染引擎**：DR-M0 已先行的 PlaybackPort / StylePort 契约层是引擎无关的
  （主线仓 `1fde125`，四件文件禁 import 任何渲染库），本裁决不影响契约层。
- 版本口径：推荐范围 = **v5.0 及以上**（globe 正式内置的下限）；D3 实施时锁定当时最新
  稳定 minor 并在卡 evidence 记录版本号（默认按 npm `latest` = v6 线；若实施发现 v6 有
  破坏性变化，回退 `latest-5` = 5.24.1 仍在推荐范围内）。
- 包体积为**观察值**：bundlephobia v6.18.0 = min 1,106,255 B / gzip 297,616 B——
  以实际构建为准；经岛屿懒加载 chunk 不进首屏（§5 核对表第 6 条）。

## 4. 推荐理由链

**4.1 数据形态决定引擎需求面——本项目不需要任何外部瓦片服务。**
地图内容 = 自托管 GeoJSON（177 国，243KB，`1fde125` 已入库，Natural Earth 公有领域）
+ 自托管背景色层（DR-M2 的 style JSON，MASTER token 映射）。没有街道/地形/卫星瓦片
诉求。因此引擎只需要提供三件事：**投影（globe）+ 渲染（矢量面/线/状态染色）+ 拾取
（click/queryRenderedFeatures）**。MapLibre 恰好只在这三件事上用引擎，其余全部自托管
素材——运行时外部请求为零，与乙-5 完全兼容。

**4.2 globe projection 开箱即得 = 复刻 §2.5「3D 是引擎送的」结论，零自研 3D。**
MapLibre v5.0.0（2024-12-31 发布）把 globe 投影收为正式特性：`Support globe mode
(#3963)` + `New GlobeControl (#4960)` + globe 大气（#3888）+ globe 地形（#4976）。
Radiooooo 的地球观感三件——globe 外圈光晕（setFog/大气）、`renderWorldCopies:false`、
`maxZoom:6`——在 MapLibre 上全部有对等参数；§2.1 的分层架构（底图样式 / GeoJSON 层 /
feature-state 染色 / 相机 / 交互）逐层可平移，M2–M4 卡面无需因换引擎重写。

**4.3 排除 three.js / globe.gl：3D 能力过剩且与「地图语义」错位。**
需求是地理投影地图（国家面 + 五态染色 + 标注），不是通用 3D 场景。走 three 路线则
地图投影、多边形三角化、射线拾取、标注避让、缩放层级全要自研——等于把 MapLibre 内部
重写一遍；且包体积观察值反而更大（globe.gl gzip 559KB > MapLibre gzip 298KB，two 件
叠加）。设计参考 03 §5.3 DR-M1 卡面对此预判「重，3D 能力过剩」，实测数据支持。

**4.4 排除纯 Canvas 2D 自研：零依赖最轻，但投影/交互/标注全自研，维护成本最高。**
正交投影近似 globe 观感退化（无大气、无边缘曲率、无平滑缩放投影切换）；缩放时的
坐标换算、多边形点选拾取（point-in-polygon 手写或引 earcut 类库）、feature 状态管理
全部own-code——每一条都是长期维护面。DR-M0 端口契约虽可接，但端口之下零现成件。
仅当未来「globe 岛屿被证明过重」时作为回退预案保留，不作首选。

**4.5 排除 Mapbox GL JS：乙-5 一票否决。**
Radiooooo 同款不假（§2.4：五套 `mapbox://styles` Studio 样式 + `setStyle(diff:false)`），
但 Mapbox GL JS v2.0（2021-01）起 License 从 BSD-3 转为**专有**、**强制 accessToken**、
按 map load 计费且升级即同意其 ToS（npm 现值 3.35.0 license = "SEE LICENSE IN
LICENSE.txt"）；其样式/瓦片/字体 glyph 均走 Mapbox 云服务——三项全撞乙-5「资产自托管
零 CDN」+ 隐私红线（匿名零外发不成立：地图加载即向 Mapbox 发请求）。
