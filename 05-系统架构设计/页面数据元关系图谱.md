## 1. 数据元总归类（先归类再连线——红线归属由类别决定）

| 数据元（表/载体） | 类别 | 关键字段/内容 | 红线属性 |
|---|---|---|---|
| `album_metadata` | **外部元数据** | title/artist/cover_url/cover_local（磁盘缓存文件名）/release_year/genres/country/source/source_id/alias_sources（对象数组，D3 裁决=主线唯一权威） | 可重新同步、可补全（B10 口径）；**upsert 保守合并**（IM-12：undefined 字段保现值） |
| `collection_record` | **用户资产（核心事实对象）** | album_id 1—N/added_at/listened_at/listened_precision/is_favorite/note/cover_color（派生缓存，D3 管线回填）/user_id | **任何同步不得无条件覆盖**（产品原则 §数据原则）；重复添加=集合语义不产生第二条（FR-4 D2） |
| `tags` + `record_tag` | **用户认知体系** | tag 名（UNIQUE user_id+name）/record 关联 | Tag 与 Genre 语义分离；merge=合并语义（P1-6，旧名消失引用保留） |
| `saved_views`（0003） | 查询状态（用户） | name（UNIQUE user_id+name）/query_json | 只存查询状态不存数据（P1-10）；DD3 联动 |
| `topster_views`（0004） | 策展 View（用户） | title/subtitle/**item_order（JSON 数组 [record_id,…]，顺序即叙事）**/created_at | **Topster = Collection 的 View，无第二套数据**（乙-7）；成员失效按实际在场导出 |
| `color_palette` | 静态枚举（无表） | CoverColor 1–16 → COLOR_TABLE（html.ts 整数唯一展示事实源） | 16=保留值（渲染灰兜底；与 13 双 chip 消歧待用户裁决） |
| 封面文件缓存 | 磁盘资产 | `data/covers/`（sha256 内容寻址，/covers 流式） | 禁 base64（乙-10）；可重下载（外部元数据衍生） |
| `public/geo/`（ countries-110m.json / availability.mock.json） | 静态资产 | Natural Earth 110m 公有领域 / G2 白名单替身 | 乙-5 自托管零 CDN |
| cookie（mg_session / mg_sensory / tag-hint / metrics 开关） | 会话/偏好态 | 无表（V10 无状态会话；感官层/提示关闭/匿名计数） | 隐私红线：缺省安静、匿名可关闭 |

## 4. 红线标注（本图谱的存在意义之一）

1. **用户资产写入点全清单 = P9/P12/P13/P14/P15/P17/P19/P23**——任何同步/补全/迁移机制
   （如 mb-calibrate、未来 netease 补全）**只允许写 album_metadata 外部字段**且必须走
   IM-12 保守合并（undefined 保现值）；触碰上清单内字段 = 违反产品原则「数据原则」节。
2. **DD3 URL 即状态落点**：P3/P25（query 全量状态）/P21（漫游位置不入链=DR-M4 边界）/
   P17（saved_views = 查询状态持久化）；chips=`<a>` 语义（P4/P5）受乙-1 保护——React 化
   不得降级为 JS-only（S2-3 评审案 §5.2 新表述）。
3. **全表读豁免两则**：P27/P28（panoramaNodes）与 P33（exportAll）——内存纪律①LIMIT≤60
   的显式豁免先例，新增全表读必须另走评审（豁免清单不开放自扩）。
4. **外部调用面**：P6（chain 搜索）/P11（iTunes 预览）——全部过全局串行 ≥1s + 30/min
   限流纪律（乙-4）；预览零落库（P11 显式口径）。
