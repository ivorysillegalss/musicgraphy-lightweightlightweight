### 2.2 端点清单（已登记进 `02 文档 §4` pages 域节）

| Method | Path | 说明 | 三态行为（B-track 未就绪时） |
|---|---|---|---|
| GET | `/` | Collection 主页（回响区→筛选舱→状态行→封面墙→分页） | 回响静默跳过；舱壳保留；墙区 = `errorStrip` + 重试链接 |
| GET | `/add` | 添加表单（无 JS 基线） | 表单照常渲染 |
| POST | `/add` | 落库 → 303 `/?flash=added`；409 → 303 `/album/:id?flash=duplicate`（C-DUP）；失败 → 303 `/add?flash=error`（不阻塞） | 失败路径可直接验证 |
| GET | `/album/:id` | 详情双区 + 联想入口（馈赠：失败整区不渲染） | DAO null → 404 引语页；异常 → errorStrip 页 |
| POST | `/album/:id/favorite` | Favorite 开关（无 JS 表单）→ 303 返回详情 | 失败静默 303 |
| GET | `/fragment/cabin` | 筛选舱片段（岛屿 F1 swap 用） | 503（岛屿注入错误态的信号） |
| GET | `/fragment/wall` | 封面墙片段（含状态行/空态/分页） | 503 |

### 2.3 子 Agent 必须遵守的约定

1. **URL 参数命名（DD3）**：`q` `genre` `year`(发行) `period`(听的年份 YYYY) `fav` `tag` `color`(1–15) `cursor` `flash`。所有 chips/链接经 `buildHref` 语义生成；禁止发明第二套参数名。
2. **三态助手复用**：任何新增 UI 的 loading/empty/error 一律用 html.ts 的四个助手 + `app.css` 现成类（`.skeleton/.empty-quote/.error-strip/.flash*`），禁止另写形态。
3. **冻结文件**：`routes/html.ts`、`routes/pages.ts`、`client/main.ts`（除注册表加行）、`client/styles/*` 在 F1–F4 期间冻结；确需改动 → 在本文档 §6 登记 + 评审（PM §7.5 提交引用编号）。
4. **骨架期已修问题（登记）**：`server/static.ts` 挂载前缀 bug（原实现把 `static/...` 拼进 root 导致所有静态资源 404）——F0 验证期修复，B-track 知悉；`hono/html` 的 `HtmlEscapedString` 类型未 re-export，从标签派生（html.ts/pages.ts 已统一）。
5. **门禁**：`npm run typecheck && npm run lint && npm run build` 全绿；岛屿 <150 行；首屏 JS ≤30KB（F0 实测 main.js 1.85KB gzip 1.05KB）；封面 1:1 防 CLS；内存五纪律。
