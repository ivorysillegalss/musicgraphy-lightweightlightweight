## 0. 站点速览（30 秒版）

- **产品**：Radiooooo =「时间机器」电台——地球选国家 + 底部年代条选 1900s–2020s，播对应年代对应国家的曲库。
- **形态**：纯客户端 SPA（`app.radiooooo.com` 单 HTML 壳 + Vite 动态 import 按路由切片），**无 Vue/React/Svelte**
  ——自研 class 组件框架（声明式 `layout` 数组 + publish/subscribe 事件总线）。
- **音乐渲染三件套**：HTML5 `<audio>` 渐进式下载（无 HLS/MSE）→ Web Audio API 调音台 → Canvas 2D 示波器可视化；
  空间界面 = Mapbox GL JS WebGL 地球。**没有第三方播放器/可视化库，全部手写。**
- **移动端**：混合架构——同一套 UI，检测到 iOS/Android 即 `disableWebPlayer()` 移除 DOM 音频，
  走原生播放器 JS 桥（`ios.player.time` / `android.player.time` 事件回传）。

## 1. 音频渲染管线（核心）

### 1.1 真实信号图（bundle 还原）

```
<audio class="a1"> ── createMediaElementSource ──┐
<audio class="a2"> ── createMediaElementSource ──┤
                                                 ▼
                                          GainNode（主音量）
                                                 ▼
        10 段 BiquadFilter 串联 EQ：
        32Hz lowshelf · 64/128/256/512/1k/2k/4k/8k peaking（Q=1）· 16.4kHz highshelf（±12dB clamp）
                                                 ▼
                     AnalyserNode（fftSize=2048 · smoothingTimeConstant=0.8）
                                                 ▼
                                        audioContext.destination
```

### 1.2 关键机制逐条（原理层）

| # | 机制 | 实现（代码证据） | 原理点评 |
|---|---|---|---|
| 1 | **双通道 A/B 播放器** | `buildAudio()` 动态 `createElement("audio")` ×2，各挂 `<source type="audio/mpeg">` + `<source type="audio/ogg">`，`crossOrigin="anonymous"` + `controlsList="nodownload"` | 双通道本质 = **无缝续播缓冲位**（非双声部混音）；格式选择交给浏览器 `canPlayType`（ogg vorbis / mp4a.40.5 / mp3 探测在档） |
| 2 | **曲目获取 = API 驱动** | `getTrack()` → `POST /track/play/{id}`（携带上下文）→ 返回 `{links}` → 塞进 `<source>`；音频托管 `asset.radiooooo.com` | 前端零解码参与，只做「接线」；**渐进式下载**（整文件拉取），无流媒体协议 |
| 3 | **crossOrigin=anonymous 是分界线** | 元素级 CORS 声明 | 没 CORS 头 → MediaElementSource 输出被「污染」→ AnalyserNode 全吐零。**「能播放」与「可分析」的分界线就在这一行** |
| 4 | **交叉淡化** | `cross()` 把新曲设进空闲通道 → `fade()` 用 `setInterval` 100ms 步进 `element.volume`（默认 3s，step 0.02）；A/B 通道 `this.line` 翻转 | **没用 GainNode.linearRampToValueAtTime**——JS 定时器步进主线程量，抖动会有毛刺；音量走 GainNode、淡化走 element.volume 两套并存，属「够用不精确」取舍 |
| 5 | **续播预判** | 进度条监测 `currentTime > duration - (crossfade时长+1)` 即提前 `publish("player.end")` | 提前量给网络缓冲留了余量，换曲感知上无缝 |
| 6 | **EQ** | 10 段 BiquadFilter 串联，`setValueAtTime` 实时改 band gain（±12dB clamp） | Web Audio「调音台」职能的标准做法；EQ 链在 AnalyserNode **之前** → 可视化反映的是处理后的最终信号 |
| 7 | **OS 级媒体控制** | `mediaSession.metadata = new MediaMetadata(...)` | 锁屏/媒体键接系统播放器 |
| 8 | **自动播放解锁** | 100×50 静音空白视频 `muted-blank.mp4/ogv` 循环播放（`prevent()`），允许播放后 `allow()` 停掉 | 经典移动端 autoplay 策略旁路（哑视频解锁手势链） |
| 9 | **移动端原生桥** | `platform==="ios"/"android"` 分支 + `disableWebPlayer()`；原生侧回传 time/buffer 事件 | Web 端才跑 Web Audio 图；原生端音频在原生层渲染，UI 复用同一套组件 |

### 1.3 音乐可视化（可选项）

- 开关：`setting.player.visualization.enabled` → player 加 `mode-visualization` class，向 body 插 `<canvas>`。
- 渲染循环：`requestAnimationFrame` → `analyserNode.getByteTimeDomainData()` → **2D Canvas 时域示波器**
  （白色 0.7px 细线 `rgba(255,255,255,.8)`；`devicePixelRatio` 适配；resize 重建画布）。
- 生命周期纪律：非激活 `cancelAnimationFrame` 释放；初始化幂等（`_visualizationInitialized` 哨兵）。
- 类型注册表 `Mi={waveform:...}` **目前只实现 waveform 一种**（无频谱柱状图）——留扩展位未填。

## 2. 地球展现：整体是怎么做的（用户重点问项）

**一句话**：地球不是自研 3D，也沒有 three.js——是 **Mapbox GL JS（WebGL 矢量瓦片引擎）的 globe 投影模式**，
上面叠一层**自托管 GeoJSON 国家面**，用 **feature-state 数据表达式五态染色**，再配 **相机编排**（flyTo/easeTo）
与**大气雾效**（setFog）。地球只是「渲染皮肤」，全部交互语义发生在 GeoJSON 图层上。

### 2.1 分层架构（自上而下）

```
┌─ 交互层：click/mousemove 监听（countries-layer + country-labels）
├─ 业务层：availableCountries 白名单 → setFeatureState（playing/selected/empty…）
├─ 相机层：flyTo/panTo/easeTo（padding + 自定义 easing）+ NavigationControl
├─ 大气层：setFog（light/dark 两套，globe 外圈光晕）
├─ 矢量层：countries-layer(fill) + country-boundaries(line) + country-labels(symbol)
│          —— 数据源 = 自托管 GeoJSON（按年代分桶）
├─ 底图样式：自有 Mapbox Studio 样式组（mapbox://styles/radiooooo/clv…，主题×明暗）
└─ 引擎：new mapboxgl.Map({projection:"globe"|"mercator", renderWorldCopies:false,
          maxZoom:6, minZoom:0, doubleClickZoom:false, attributionControl:false})
```

### 2.2 数据流（点开网站 → 播起歌的完整链路）

1. **初始化**：`accessToken` 按域名取 public/test → `getStyle(theme)`（暗色模式合并暗色变体）→ 建 Map 实例
   → 禁 dragRotate/touchPitch（移动端防误触）→ 右下角 NavigationControl（无罗盘）。
2. **底图**：`loadMapBase()` 拉 `base.geojson` 作底图要素；样式切主题 = `setStyle(url, {diff:false})` 整换。
3. **可用国家**：`GET /country/mood?decade={d}` 拉该年代有曲库的 isocode 白名单（客户端按年代缓存）；
   `GET countries/{lang}.json` 取本地化国名（切语言即重拉）。
4. **年代 GeoJSON 分桶**：`getGeodataFile(decade)` 把 12 个年代映射到少数几份边界文件
   （1900/1910/1920 → `1900.geojson`；2010/2020 → 同桶）——**历史边界不同年代不一样**（苏联/奥匈等），
   按桶复用省请求；`loadMap()` 合并 base + 年代要素 → `P(features, countryNames)` 挂本地化属性 →
   `addLayers()` 注册 `countries` 源 → **客户端 `cachedGeoJsonData` 按桶缓存**，二次切换零网络。
5. **染色**：`updateCountries(availableCountries)` 对每个国家要素 `setFeatureState`——白名单内 = 可点态，
   白名单外 = `empty` 态（近乎透明）。
6. **交互**：
   - `map.on("click","countries-layer"|"country-labels")` → 校验 isocode ∈ availableCountries，
     不在 → `publish("country.empty")`（toast 通知）；在 → 进入选年代流。
   - `mousemove/mouseleave` → 仅白名单国家换 `cursor:pointer`。
   - 相机：`focusByIso/focusByFeature` → `flyTo/panTo`（`easeTo` 带 padding 与自定义 easing 曲线）。
7. **年代条**：点击国家后 API 返回可用年代 → 底部横向 decades chips 条（`scrollToCenter` 居中激活项，
   播放中的年代 chip 加 `playing` class）。
8. **播放态回写地图**：播放开始 → 该国 feature-state `playing=true` → 填充表达式自动变品牌橙
   `#F95101`（不重传任何数据）。换国家/清空态 = `highlight/unHighlight` 增量反转 feature-state。
9. **标签层**：`createLabelPoints()` 由国家面生成标注点（`country-labels` symbol 层，点击同义）。

### 2.3 五态染色表达式（设计核心，原文摘录）

`countries-layer` 的 `fill-color` / `fill-opacity` 是 **Mapbox 数据表达式**（GPU 侧求值，改状态零重绘上传）：

```js
"fill-color": ["case",
  ["boolean", ["feature-state", "playing"],  false], "#F95101",   // 播放中 = 品牌橙
  ["boolean", ["feature-state", "selected"], false], "#F95101",   // 选中 = 橙（浅）
  ["boolean", ["feature-state", "premium"],  false], "grey",      // 付费墙国家 = 灰
  ["boolean", ["feature-state", "empty"],    false], "grey|white",// 无曲库年代 = 近隐身
  ["boolean", ["feature-state", "hover"],    false], "#F95101",   // 悬停 = 橙
  "#F95101"],                                                     // 基色 = 橙
"fill-opacity": ["case", playing→0.6/0.7, selected→0.3, premium→0.2, empty→0.08/0.15, …]
```

**原理点评**：`feature-state` 是 Mapbox 的「每要素可变状态」机制——**数据不动，状态动**。
五态全靠预置表达式 + `setFeatureState` 增量切换，比重发 GeoJSON 快几个数量级，
这是「整个地球都是按钮」仍能 60fps 的关键。

### 2.4 主题系统

- 五套主题：`blue / orange / vintage / legacy / classic` ×明/暗模式，实现 = **自有 Mapbox Studio 样式 URL 组**
  （`mapbox://styles/radiooooo/clvp9ecc…` 等），切主题 = `getStyleId(sprite)` 比对后 `setStyle(diff:false)`。
- paint 微调（fill/line/text 三组）经 `setPaintProperty` 覆写，不重制样式。
- `legacy` 特例：隐藏全部矢量层（遍历 `getStyle().layers` setLayoutProperty visibility none）+
  `addCustomRasterBackground()` 挂自有 raster tiles（`legacy-background`）——**复古纸质地图观感用栅格底图实现**。
- admin 可上传自定义样式 URL（`uploadMapStyle`，代码里 `theme==="cutom"` 拼写错误为原样证据）。
- 大气：`updateFog()` 光/暗两套 `setFog`——globe 模式的外圈空间光晕即来自此。

### 2.5 原理总结（三行）

1. **3D 是引擎送的**：Mapbox GL v2.9+ 的 globe projection 开箱即得，Radiooooo 零 3D 代码；
   自己写的只有「数据接入 + 状态染色 + 相机编排」。
2. **状态渲染 > 数据渲染**：五态全走 feature-state 表达式，交互期间零数据重传。
3. **成本重心在内容不在技术**：真正的功夫 = 按年代分桶的历史边界 GeoJSON 生产 + 五套 Studio 样式调色，
   技术面反而薄。

## 3. 工程形态旁注（可参照/勿照搬）

- **自研 UI 框架**：class 组件 + 声明式 layout 数组 + 事件总线；Vite 按路由切片（map/player/islands/…），
  i18n 按语言切片。主 bundle 305KB 外壳，业务全懒加载。
- **CSS 极简动效姿态**：119KB CSS 仅 `spin`（加载圈）+ `jiggle` 两个 keyframe，其余全靠 300ms transition
  ——「渲染力」都押在地图与音频上，UI 本身静态克制。
- **混合 App**：同一套 Web UI + 原生播放器桥（iOS/Android 分支遍布播放器代码）。

**第 0 步 · DR-M0（新增卡）接口契约先行**（规模 S，无前置，最先做）：

- **落点**：`src/client/islands/globe-view/ports.ts` + `adapters/null-playback.ts`（新建目录）

| 波次 | 卡 | 内容 | 完成态 |

**预留接口验收口径（DoD）**：**「换实现零改地图」**——把 NullPlaybackAdapter 换成 MockPlaybackAdapter
（或未来真音频实现）时，地图渲染层 diff = 0；`setTheme()` 切换复用 Radiooooo 语义
（`setStyle(diff:false)`，§2.4）。

**最小可跑骨架（walking skeleton）验收链**：打开页面 → globe 渲染自托管 GeoJSON →
hover/点击国家白名单校验 → 五态染色（Mock 播放态）→ `setTheme()` 即时切换 → 维度状态入 URL。
达成即骨架收口，播放与更多主题随后**换插座**接入，地图模块零重构。

**排序原理四则**（为什么是这个顺序）：① 契约先行（缝不返工）；② 数据与裁决并行
（互不依赖、各自阻塞下游）；③ 样式先于图层（substrate 顺序）；④ 交互最后（正交于渲染内容，
实现换插座优于提前实现）。
