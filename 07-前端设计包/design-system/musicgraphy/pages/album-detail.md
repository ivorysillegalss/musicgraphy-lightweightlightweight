## 布局结构（Desktop 1440）

```
┌──────────────────────────────────────────────────────────────┐
│ ◁ 返回 Collection                                             │
│ ┌────────────┐  外部元数据区（公共事实，数据源代填）              │
│ │  封面 320px │  专辑名 (Display/H1) · 艺术家 · 发行年份          │
│ │  +主色点    │  Genre chips（钢墨描边——公共属性的视觉身份）        │
│ └────────────┘  数据源标注 (mono 11px): VIA MUSICBRAINZ          │
├──────────────────────────────────────────────────────────────┤
│ 个人记录区（「记忆条」第一人称重组——你的档案）                    │
│ 「2023 年 8 月记录 · 听的时期：2023 夏 · Tags：夏天 / 海边        │
│   · 当时：青旅的天台」                                           │
│ [★Favorite] [+又听了一次] [✎补线索]                             │
├──────────────────────────────────────────────────────────────┤
│ 联想入口 (P1-5): 同期听的 6 张 | 同天添加的 6 张 | 同 Tag 的 6 张   │
└──────────────────────────────────────────────────────────────┘
```

## 本页覆盖规则

1. **双区视觉分区是硬规则**：外部元数据区与个人记录区之间用 hairline + 区题（mono「PERSONAL RECORD」）分隔；用户数据用琥珀注记语气，公共数据用钢墨语气——"§4 元数据/用户数据二分"的视觉执行。
2. **"当时"注记**：Playfair Display Italic 呈现，前缀琥珀手写符号「❞」改用 Lucide `quote` SVG；这是全产品唯一 Playfair Italic 场景——注记 = 手写体的隐喻。
3. **联想入口**：三组各 ≤6 张封面（master 规则），组题 mono 大写；**禁推荐语气**，组题即确定性语义（同期/同天/同 Tag），不得出现"猜你喜欢/相关推荐"字样。
4. **重听动作**：次级按钮「又听了一次」点击后 toast 确认（mono：「LISTENED AGAIN · LISTENEDAT → 2026-11-11」），不弹确认对话框。
5. **主色点**：封面左下角 10px 圆点 = 该记录 D3 主色字段值，title 提示色名（红/蓝/…），色名文字同时出现在记忆条中（不单靠颜色）。
