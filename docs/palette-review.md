## 1. 背景

P1-4（PM §2.1 W6）= 颜色轴色板设计。色板映射已随 D0 设计系统成文（MASTER.md
「封面主色数据色板」）并落地为 `html.ts COLOR_TABLE`（1–15 有效值 + 16 保留值按灰兜底，
「UI 不发明新色」纪律）——本评审案裁决的是**呈现口径**与两笔移交项，而非重画色板。

## 2. 数据输入（W4-6-1 实测定谳）

- 真实库 41 张封面回填分布：黑 22 / 白 14 / 灰 3 / 青 1 / 品红 1，**蓝(8) 命中 0**。
- 6 张真蓝封面原图目检：提取忠实——真蓝封面多为去饱和 navy（→黑/灰）或高明度淡蓝（→白），
  色板 8=#2563EB 饱和中蓝在真实库是天然长尾。
- 种子库遗留：cover_color=16 保留值 285 张与 13 同显「灰」（O5 观察项，另案）。

## 3. 裁决

- **Q1 色板映射维持不变**：1–15 ↔ MASTER.md 色名/色值是冻结契约（存储层只存整数，
  COLOR_TABLE 是唯一展示事实源）；不增色、不改值、不重排。理由：重画色板 = 存量
  cover_color 全量重算 + MASTER/设计 PRD 联动改版，收益不成立（见 Q2）。
- **Q2 蓝轴长尾 = 如实呈现，不硬凑**：筛选舱 chips 已有实时计数 + **零计数自动隐藏**
  （W4-6-2 验收点）——蓝 chip 无匹配时自动消失，有匹配时如实显示计数；用户按计数自辨。
  「蓝 = 饱和中蓝」是 MASTER.md 的设计定义，与真实封面去饱和趋势的落差是**数据事实**，
  不是提取缺陷（目检对照已定谳）；任何「放宽蓝色判定」都要动提取管线（IM-18 口径），
  收益存疑、代价全量重算，不做。
- **Q3 密度三档 = v1 维持单一标准密度**，密度切换（紧凑/宽松档）登记观察池 **O9**：
  触发条件 = 真实用户反馈密度不适（口碑记录留痕）；约束 = 现 CSS 产物 19.02KB / 20KB
  预算（IM-14）无增量空间，新密度档必增规则，届时随评审+预算复核一并立项。
  （W3-1 移交项就此销项。）
- **Q4 O5（16/13 双灰）维持观察**：消歧涉种子库生命周期（种子清空即自然消解），
  不属本卡裁决范围。

MASTER.md 与 W4-6-2 交付的形态，无需代码变更；CSS 零增量（IM-14 预算内）。
