# perf-5000 —— FR-5 规模底座实测报告（W3-1）

> 实测脚本：`scripts/perf-5000.ts`（node:perf_hooks；真实 Hono 服务 + data/db 5000 张种子库）。
> 复现：`npm run build && npm run seed 5000`（如 `data/db/musicgraphy.db` 不存在）→ `node --import tsx scripts/perf-5000.ts`。
> 实测环境：Node v26.13.0 portable · Windows 10 x64 · 127.0.0.1（无网络延迟）· 2026-11-13。
> **口径披露**：本报告为 Node 侧代理指标——「DOMContentLoaded」以 **SSR HTML 完整收到** 为代理（本地解析开销可忽略），
> 「可交互」以 **HTML + 全部 /static 资源（含岛屿 chunk 两波加载）就绪** 为代理。SSR 直出无 hydration（ADR-003），
> 岛屿 `mount()` 为微任务级 DOM 叠加，浏览器内真实 TTI 与代理值差异主要来自脚本解析执行（gzip 后 <8KB，亚毫秒级）。
> CLS 为纯浏览器渲染指标，Node 侧不可测（见 PRD §9 对照表第 2 行披露）。

## 1. 首屏可交互（三次取中位，PRD §9 预算 <1s）

| 轮次 | TTFB | HTML 完整收到 | /static 全就绪 | **可交互** | SSR HTML |
|---|---|---|---|---|---|
| run1 | 31.0ms | 31.4ms | 8.3ms | **39.7ms** | 70,332B |
| run2 | 30.4ms | 30.7ms | 3.7ms | **34.4ms** | 70,332B |
| run3 | 30.5ms | 30.8ms | 3.3ms | **34.1ms** | 70,332B |
| **中位** | **30.5ms** | **30.8ms** | **3.4ms** | **34.4ms** | **70,332B** |

- **可交互中位 34.4ms = 预算 1000ms 的 3.4%**（余量 29 倍）。
- /static 共 **7 件 / 30,397B**（main.css 19,029B + main.js 2,391B + 5 岛屿 chunk 合计 8,977B，未压缩字节）；
  HTML 引用 main.css/main.js，main.js 动态 import 5 个 chunk（wall-scroll 1.54KB/gzip 0.92KB、
  filter-cabin 1.43/0.88、add-dialog 3.78/1.57、search-box 1.69/1.00、keyboard-flow 0.50/0.34）。
- SSR HTML 70,332B（68.7KB）≤ 80KB 预算线（W2-1 口径延续）；60 张封面卡直出，无 JS 也可浏览（V4 基线）。

## 6. 实现口径说明（虚拟滚动 vs LIMIT 60 + 无限追加）

PRD §9 首屏行提及「虚拟滚动」；本实现按 PM §2.1 FR-5 行的落地口径执行：
**LIMIT 60 cursor 分页（ADR-005 内存纪律①）+ IntersectionObserver 无限追加（第 5 岛屿 wall-scroll）**。
5000 张全量下 DOM 稳态上限 = 实际滚动到的卡片数（每页 60 张渐进上墙，非一次全挂）；
RSS 78MB 实测证明无内存压力。真·虚拟滚动（窗口化 DOM）列为观察项：仅当单墙 DOM 节点实测造成
交互卡顿时再评估（当前余量巨大，YAGNI）。密度三档口径冻结属 W3-1 desc 项，随 FR-2 色板轴（P1-4）一并裁决。

## 7. 结论

- **FR-5「5000 张 <1s」达成**：可交互 34.4ms（中位）≪ 1000ms，SSR HTML 与资源预算全过。
- **追加链路数据完整**：三页各 60 张零白屏，cursor 全程服务端下发；错误态注入 .error-strip（禁吞错、禁 alert）。
- **无 JS 基线不破坏**：分页 `<a rel="next" data-next>` 原生跳转是兜底，岛屿只做增强（ADR-003 复审 V4）。
- 遗留观察项：CLS 浏览器实测（P2 回归一并做）、真·虚拟滚动（观察池，不排期）。
